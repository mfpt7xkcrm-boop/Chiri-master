# 地理 Master v1.2（選択肢品質改善）

GitHub Pages対応。既存のファイル5点を上書きアップロードしてください。

## v1.2 変更内容
- 雨温図13種類の誤答候補を、紛らわしい気候グループから明示指定（例：DfならDw・Cfb・ET）
- 国名29か国は近隣の国を中心に選択肢を構成
- 用語問題は同系統の概念を優先し、分野が異なる選択肢の無意味な混入を減らす
- テストで暗記不要の料理名3件を出題対象から除外
- 雨温図の解説に判断手順を追記
- 学習記録のキー `chiriMaster_v2` と既存問題IDは維持

## 重要
選択肢が似ていることと、問題が一意に正しいことは別。気候は実データの細部で境界判定が必要な場合があるため、雨温図は学習用模式データとして利用すること。


## v1.3 雨温図2段階判定
雨温図は「気候区分」→「判断根拠」を連続出題します。両方正解した場合に限り、その雨温図の正解1回として学習記録に反映します。途中の一問目で誤答しても、根拠を選ぶ機会があります。従来の学習記録キーと設問IDは維持します。
